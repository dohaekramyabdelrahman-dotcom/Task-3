1-Class vs struct vs record
التلاتة بنستخدمهم لتعريف أنواع بيانات (Types)، لكن بيختلفوا في طريقة التعامل مع البيانات، والمقارنة بين الـ Objects، والاستخدام المناسب لكل نوع

class<بستخدمه عشان امثل كيان عنده بيانات وسلوك وممكن حالته تتغير اثناء تشغيل البرنامج 
وهو reference type يعنى المتغير يحتفظ بمرجع من ال object مش نسخه مستقله من بياناته بستخدمه لما امثل كيان ف النظام ولما احتاج اغير بيانات الobject ولما يكون عندى علاقات بين الobject و الوراثه وسلوكيات مختلفه >
struct< شبه ال class فى انى اقدر اعرف جواها method و Properties لكن الفرق الاساسى انها value type 
استخدمه لما امثل قيمه صغيره وبسيطه زى اللون او نقطه احداثيات ويفضل يكون قيمتها غير قابله للتغيير بعد انشائها ومكان التخزيين يعتمد عل السياق >
record< مناسب لما تكون البيانات نفسها هى الاهم وبنحتاج مقارنه بين ال object فى الذاكره 
بستخدمه فى نقل البيانات بين اجزاء التطبيق و لما تكون المقارنه بين البيانات بالقيمه نفسها مهمه >
